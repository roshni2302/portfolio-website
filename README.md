# 🌐 Personal Portfolio Website

## 📌 Project Overview

This is my Personal Portfolio Website developed as a First-Year B.Tech Computer Science Engineering project. The website showcases my skills, projects, achievements, certificates, and contact information in a professional and user-friendly format.

The portfolio is fully responsive and accessible on desktop, tablet, and mobile devices.

## 💻 How to Run Locally

1. Clone the repository:

git clone https://github.com/roshni2302/portfolio-website.git

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Run using Live Server.

5. View the website in your browser.
